# Requerimientos — Análisis del Sistema

Corresponde a las actividades "Levantamiento de requerimientos", "Análisis de procesos actuales", "Identificación de requerimientos funcionales/no funcionales" y "Elaboración de casos de uso" del cronograma (semanas 36-39).

Este documento es el entregable "Documento de análisis y requerimientos" mencionado en el Gantt.

## Cómo levantarlos

Idealmente en una o más sesiones con el asesor empresarial (Juan Alexis García Gómez), revisando el proceso actual paso a paso para cada módulo. Preguntas guía por módulo:

- ¿Quién hace hoy esta actividad y con qué herramienta (Excel, papel, Word)?
- ¿Qué datos captura exactamente? (para no inventar campos que luego no se usan)
- ¿Qué reportes o documentos se generan al final?
- ¿Qué reglas tiene que sí o sí se deben respetar? (por ejemplo, requisitos de CONOCER para las constancias)
